# JemTek-Flow — Permanent Rules

## Token Efficiency
Never print full files, tables, or long summaries in chat. Reply in 2-3 lines max after committing.

## Richard-Style Design Sheet
- **Resolution**: 1080x1920 (9:16), 60fps
- **Background**: Pure black `#000000`
- **Glow**: SVG `<feGaussianBlur>` neon bloom filters on all vectors/text
- **Floor**: Dashed line at Y=1350, mirrored reflection (`scaleY(-1)`, opacity 0.2, blur 4px)
- **Avatar (JemAvatar)**: Silhouette with glowing eyes, `#FFD166` gold tie
- **WireframeBox**: 3D neon wireframe, `#00F5D4` cyan / `#FF3366` red
- **AnimatedCounter**: Smooth count with semantic color glow
- **SubtitleBar**: Bottom word-by-word glowing captions

## Semantic Palette
- **Gold** `#FFD166`: Smart AI/tech moves & hero tie
- **Red** `#FF3366`: Hacks/traps/errors
- **Cyan** `#00F5D4`: Speed/protection/gains
- **White** `#FFFFFF`: Neutral UI
